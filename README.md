# React Admin Dashboard

A responsive admin dashboard built with React and TypeScript, using a simulated API backend.

## Live Demo

[https://react-admin-dashboard-chi-roan.vercel.app](https://react-admin-dashboard-chi-roan.vercel.app)

## Features

- Responsive design
- Built with React and TypeScript
- State management with Redux
- Simulated API integration
- Course management module
- Paginated data tables with DataGrid
- Authentication with loading states and remember-me

## Quick Start

```bash
git clone https://github.com/amirtanazzoh/react-admin-dashboard.git
cd react-admin-dashboard
pnpm install
pnpm run dev
```
